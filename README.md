# Twin Beans Farm — Ayurvedic Dosha Quiz

A lightweight bilingual Prakruti and Vikruti questionnaire deployed as a static Netlify site. The quiz has 31 questions across three sections and preserves answers in local storage. Netlify functions provide result-link sharing.

No build step is required. Serve the repository root with any static web server.

```sh
python3 -m http.server 8000
```
